# Riftbound Threat Trainer

A React + TypeScript prototype to help Riftbound players learn which cards an opponent can still play based on champion and remaining Energy.

## Current Prototype

- Opponent champion selection (currently Viktor)
- Remaining Energy selection from 0 to 10
- Live list of playable cards up to selected Energy
- Local JSON card database with:
  - Stupefy
  - Blood Money
  - Wages of Pain

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run lint
```
